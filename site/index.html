Your watch

Connect the watch by USB and wait for it to appear as a drive, then pick it below.

This browser can read the watch but cannot write to it — only Chromium-based desktop browsers (Chrome, Edge, Opera) implement the directory-write API. You will get a ready-to-run install script instead. For the same reason this browser cannot remember the folder, so it has to be picked each visit.

          Your own app can be listed here. You send a repository, a
          commit and the SDK release to build against — never a binary. Kira compiles it
          in the same pinned toolchain as everything above, checks the result against
          what your CMakeLists.txt declares, and lists it in these same
          grids with the source and commit shown on its card.

Questions and problems

            on GitHub
          

          

            Kira is unofficial, and not a support channel for UNA Watch. Anything
            about the watch itself, or how an app behaves once installed, belongs with
            UNA Watch. Everything below is about Kira: this catalogue, and installing from it.
